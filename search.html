Search cars

Search the cars for sale by model and year. Both criteria may be left blank — leaving both empty lists every car. The model field matches on substrings, so typing cam will find Toyota Camry.

Demonstration data

This site keeps its data in the browser localStorage, so it is empty the first time you open it. Loading the sample data writes one demo seller and five sample cars, which is enough to demonstrate search and the detail page. Loading it again replaces the previous sample cars but never touches accounts or cars you registered and posted yourself.

About AutoLink
