How to sell your car faster

  • Write the model as make plus model, for example Toyota Camry, so buyers can find it
  • Use the year the car was built, not the year it was first registered
  • Enter the price as a whole number of yuan, without pence after the decimal point
  • Choose a photograph taken from the front three-quarter angle in good light
  • State the mileage, accident history and service record clearly to avoid repeated questions

How the photograph is processed

  1. The browser reads the original file with FileReader
  2. It is decoded into an Image object and drawn onto a <canvas>
  3. It is scaled down proportionally so the longest side is 800 px
  4. It is exported as a JPEG at quality 0.7, usually leaving only 50 to 150 KB
  5. It is stored in localStorage, so it will not appear in a different browser
